01 · WHAT IT IS

One system, two platforms, two languages.

Falcon 2.0 is the shared language for everyone building Hala Business: designers, engineers, product and content. It sets out how the product looks, how it behaves and how it speaks, so that a transfer, a card or a POS order works the same way on the web dashboard, on iOS and on Android.

Each component page shows every state, live examples you can use, mobile versions, and rules for when to use it and when not to. The values on those pages (colors, type, spacing, radius, shadows, motion) come from one set of tokens defined in Foundations.
